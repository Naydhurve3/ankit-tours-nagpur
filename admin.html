How Private/Public Works

  • Private (this page): Only owner opens admin.html. Add vehicle/image/testimonial or toggle 👁️ to hide. Data saves to browser localStorage.
  • Public (index.html): Visitors see only items where Visible = ON. Hidden items stay in admin but not displayed publicly.
  • Persist permanently: Click Export JSON and replace assets/data/site-data.json - then changes survive on all devices & after cache clear.
  • Image options: Paste Unsplash URL OR upload (base64 stored locally, ~5MB limit). For many images use URLs.
  • Future: swap js/data.js to Firebase/Supabase for cloud sync without Export.
